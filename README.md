## Python: Statistical Modeling & Machine Learning

A collection of Python projects exploring statistical modeling, machine learning, and data analysis. These projects were developed through coursework and independent experimentation to build and apply programming and quantitative analysis skills.

Areas of Focus:

 - Regression Analysis: Linear and logistic regression, predictor selection, and model evaluation.
 - Classification & Predictive Modeling: Decision trees, gradient boosting, and classification performance analysis.
 - Natural Language Processing: Text preprocessing and sentiment classification using customer product reviews.
 - Neural Networks: Implementation of neural network architectures, gradient descent, and backpropagation.

Tools & Libraries:

- Python, pandas, NumPy, scikit-learn, statsmodels, and Matplotlib
  
About This Repository:

These projects represent earlier work exploring statistical and machine learning methods. Some were completed as part of structured coursework, with additional implementation, experimentation, and analysis.
My more recent professional work focuses on mixed-methods research, customer experience analysis, and advanced SQL-based behavioral analytics.
